# htethtwe

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Start editing the home page in `src/app/page.tsx`. The page auto-updates as you edit the file.

## Common Commands

```bash
npm run lint
npm run typecheck
npm run build
npm run check
```
